# @libs/items

Feature library generated by `nx g feature-lib items`. The reference
implementations are `libs/settings` (synchronous state) and `libs/profile`
(HTTP + `rxMethod`); this library follows the same rules:

- The barrel (`src/index.ts`) exports the routes and the store — never page
  components or services, which would break lazy loading.
- `ItemsStore` is provided **on the route**, so the state is created
  when the feature is entered and destroyed when it is left.
- Other features never import this one — composition happens through the app.

Replace the placeholder state, page content and i18n values with the real
feature. The i18n keys live under `ITEMS` in
`apps/demo-app/src/assets/i18n/{en,nl,fr,pt}.json`.
